# 분자 도킹 도구 정리: Vina, Gnina, Ledock, Reduce

분자 도킹은 작은 분자 리간드가 단백질 같은 표적에 어떻게 결합할지 예측하는 계산 기법이다. 신약 후보 물질 탐색이나 가상 스크리닝에서 자주 사용되며, Vina, Gnina, Ledock, Reduce 같은 도구가 함께 언급된다.

## Vina

- AutoDock Vina는 대표적인 분자 도킹 프로그램이다.

- 리간드와 수용체의 결합 포즈를 탐색하고 결합 친화도를 점수화한다.

- 가상 스크리닝에서 많은 후보 물질을 빠르게 평가할 때 활용된다.

## Gnina

- Gnina는 Vina 계열의 도킹 흐름에 딥러닝 기반 점수화를 더한 도구다.

- CNN을 활용해 리간드-수용체 결합 포즈를 평가하는 데 초점을 둔다.

- 기존 scoring function을 보완해 더 정교한 평가를 시도할 수 있다.

## Ledock

- Ledock은 단백질 결합 부위 안에서 리간드의 가능한 결합 형태와 방향을 탐색하는 도킹 도구다.

- 유전자 알고리즘 기반 탐색 방식이 언급되는 경우가 많다.

- 도킹 실험에서는 도구별 점수 체계와 파라미터 차이를 이해해야 한다.

## Reduce

- Reduce는 단백질 구조에 수소 원자를 추가하거나 방향을 최적화하는 전처리 도구로 사용된다.

- 도킹 결과의 신뢰도를 높이려면 입력 단백질 구조의 전처리가 중요하다.

- 단백질 준비, 리간드 준비, 도킹 실행, 결과 분석 순서로 워크플로우를 구성하면 이해하기 쉽다.

## Docker와 연결하기

- 분자 도킹 도구들은 의존성 관리가 복잡할 수 있어 Docker 이미지로 실행 환경을 고정하면 재현성이 좋아진다.

- 다만 Docker는 실행 환경을 포장하는 도구이고, Vina/Gnina/Ledock/Reduce는 도킹과 구조 전처리 도구라는 점을 구분해야 한다.

## 정리

분자 도킹 도구를 정리할 때는 각 도구의 역할을 실행 순서와 연결하면 좋다. 구조를 준비하고, 도킹을 실행하고, 점수를 비교하고, 후보를 해석하는 흐름으로 보면 도구들의 차이가 더 명확해진다.
